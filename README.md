WhatsApp Scheduler using Python (No API Token)
Overview

This project allows you to send scheduled WhatsApp messages using Python without using any WhatsApp Business API token.

It works by automating WhatsApp Web through the browser using the pywhatkit library.

Features
Send WhatsApp messages at scheduled times
No WhatsApp API required
No Meta/Facebook developer account needed
Simple beginner-friendly setup
Can be extended into:
Reminder system
Alerting system
Automation bot
FastAPI service
Cron job scheduler
Requirements
Python 3.9+
Google Chrome installed
Internet connection
Logged into WhatsApp Web
